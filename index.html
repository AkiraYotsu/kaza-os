🔍 Apa itu Kaza OS?
Kaza OS adalah sistem operasi bare-metal yang berjalan langsung di atas CPU tanpa Linux atau Windows. Kernel aslinya dikompilasi menggunakan Clang → ELF binary 18KB dan dijalankan di QEMU emulator. Halaman ini terhubung secara real-time ke QEMU monitor socket!
