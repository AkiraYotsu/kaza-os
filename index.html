TERMUX INSTALLATION & SYSTEM INFO
HOW TO RUN KAZA OS IN TERMUX:
1. Open Termux on your Android phone
2. Run this quick command:
curl -sSL https://raw.githubusercontent.com/AkiraYotsu/kaza-os/main/install.sh | bash
3. Type kaza anytime in Termux to launch Kaza OS shell layer!

FEATURES:
- File System Reading/Writing (li /path, read, write)
- Minimalist Black & White + Green Terminal Interface
- Exact error reporting in RED text if directories do not exist.
